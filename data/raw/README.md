# Raw sources

No public dataset is downloaded here yet. Save future original inputs without mutation, accompanied by URL, publication/version, filename, checksum, retrieved timestamp, license and acquisition limits. See `../../docs/SOURCE_MANIFEST.md`. Do not commit large archives, confidential data or keys.

`Penmanshiel_WT_static.csv` is a real public file, kept here unmodified: Penmanshiel wind farm
data (v3), Plumley & Takeuchi, Cubico Sustainable Investments Ltd, CC BY 4.0,
https://zenodo.org/records/16807304 — MD5 `c4cd4191234c1a67a391fe5d2978256b`, retrieved
2026-09-10. It holds 14 turbine identities and siting values; it holds no SCADA and no events.
Import it with `npm run data:penmanshiel`. Everything else in this directory stays untracked.
